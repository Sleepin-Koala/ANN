# ANN from Scratch
A small neural network implementation built **from scratch with Python and NumPy**.

I made this project mainly to understand what is actually happening inside a neural network instead of just using TensorFlow or PyTorch and treating everything like a black box.

For now, it includes:

* Neurons and layers
* Forward propagation
* Backpropagation
* Gradient descent
* Mini-batch training
* ReLU, Sigmoid, Tanh, Heaviside and Softmax
* Activation derivatives
* Categorical Cross-Entropy
* Basic weight initialization

Everything is implemented manually with NumPy. The goal is not to build the most optimized neural network library, but to **understand how the pieces work together**.

Basically, this is me trying to go from:

`"I know how to use a neural network"`

to:

`"I actually understand what is happening inside."`
